## Project Description

This project is a Java-based Mini Hospital Emergency Management System developed for the CIT300 Data Structures and Algorithms module.

The system will manage patient registration, emergency treatment requests, completed treatment records, and patient visit history.

## Data Structures

The following data structures will be implemented manually:

- Binary Search Tree for patient records
- Queue for emergency patients
- Stack for completed treatment records
- Singly Linked List for patient visit history
